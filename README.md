# 대한민국 육아휴직 급여 계산기 (6+6 부모함께육아휴직)

> **공식 배포 웹사이트:** [https://bangsuhyoek.github.io/parental-leave-calc/](https://bangsuhyoek.github.io/parental-leave-calc/)

2026년 대한민국 고용보험법 시행령(제95조, 제95조의3) 및 고용노동부 공식 행정해석을 기반으로 구현된 무료 순수 정적 웹 계산기입니다.
맞벌이 부부의 6+6 부모함께육아휴직제 상한액 체계, 순차 사용 시 첫 번째 부모의 소급 정산 차액(Retroactive Top-up), 일반 육아휴직 대비 가구 추가 수령액, 한부모 특례까지 정확하게 계산합니다.

---

## 📌 주요 기능

1. **6+6 부모함께육아휴직제 완벽 지원**
   - 부모 각각 자녀 생후 18개월 이내 휴직 시작 여부 정밀 검증
   - 공통 사용 기간(`specialMonths = min(6, monthsA, monthsB)`)에 한해 6+6 특례 상한액(250만~450만원) 적용
   - 공통 기간 초과 시 일반 육아휴직 급여 규정(4~6개월 200만, 7개월 이상 80% 상한 160만) 자동 분기
2. **순차 사용 시 소급 정산(Retroactive Top-up) 계산**
   - 첫 번째 부모가 휴직 중 수령하는 금액(일반 기준)과 두 번째 부모 신청 시 일괄 지급되는 소급 차액 분리 표시
3. **가구 합산 실수령액 및 비교 분석**
   - 6+6 특례 적용 시 vs 일반 육아휴직 시 부부 합산 수령액 비교 및 추가 수령액 산출
4. **한부모 근로자 특례 및 단독 사용 모드**
   - 한부모 1~3개월 100% 상한 300만원 특례 산정 지원
   - 배우자 미사용 일반 육아휴직 산정 지원
5. **공유 친화적 URL 동기화**
   - 모든 입력값이 URL 파라미터에 실시간 반영되어 "결과 링크 복사" 버튼 하나로 배우자나 지인에게 계산 결과 즉시 공유 가능
6. **외부 의존성 제로 (No-framework, No-build)**
   - 순수 HTML5, CSS3, ES 모듈(`calc.js`)로 구성
   - 외부 런타임 요청 및 추적기 없는 완전한 프라이버시 보호

## ⚖️ 공식 산정 규칙 및 법령 근거

- **일반 육아휴직 (고용보험법 시행령 제95조)**:
  - 1~3개월차: 통상임금 100% (월 상한 250만원, 하한 70만원)
  - 4~6개월차: 통상임금 100% (월 상한 200만원, 하한 70만원)
  - 7개월차 이상: 통상임금 80% (월 상한 160만원, 하한 70만원)
  - 사후지급금(25% 유보) 전면 폐지 (2025.01.01 시행)
- **6+6 부모함께육아휴직제 (고용보험법 시행령 제95조의3)**:
  - 자녀 생후 18개월 이내 부모 각각 휴직 시작 필수
  - 지급률: 통상임금 100% (하한 70만원)
  - 월별 상한액: 1개월 250만 (※ 2025.02.23 상향 개정) / 2개월 250만 / 3개월 300만 / 4개월 350만 / 5개월 400만 / 6개월 450만
  - 부모 모두 500만원 통상임금 시 6개월간 부부 합산 최대 4,000만원 수령
- **한부모 근로자 특례 (시행령 제95조의3 제3항)**:
  - 1~3개월차: 통상임금 100% (월 상한 300만원)
  - 4~6개월차: 통상임금 100% (월 상한 200만원)
  - 7개월차 이상: 통상임금 80% (월 상한 160만원)

## 🧪 테스트 실행 방법

외부 패키지 설치 없이 Node.js 내장 테스트 러너(`node:test`)로 11개 주요 시나리오를 즉시 검증할 수 있습니다.

```bash
# 테스트 실행
node --test
# 또는
npm test
```

### 검증 시나리오 목록
1. 일반 육아휴직 1인 - 통상임금 300만원, 12개월 (예시 1: 2,310만원)
2. 일반 육아휴직 1인 - 통상임금 500만원, 12개월 (예시 2: 2,310만원)
3. 6+6 부부 순차 사용 - 통상임금 500만원, 각 6개월 (예시 3: 각 2,000만원, 부부 4,000만원, 소급 차액 650만원)
4. 6+6 부부 - 통상임금 300만원, 각 6개월 (예시 4: 각 1,700만원, 부부 3,400만원)
5. 6+6 부부 - 통상임금 200만원 (상한선 이하 100% 전액 수령 검증)
6. 하한액 70만원 검증 - 통상임금 60만원
7. 한부모 근로자 특례 - 통상임금 400만원, 12개월 (2,460만원)
8. 자녀 생후 18개월 경계값 검증 (정확히 18개월 도래일 시작 vs 하루 뒤 초과)
9. 공통 개월 수 검증 (a): 부모 A=6개월, B=3개월 (A: 1,400만, B: 800만, 소급 50만)
10. 공통 개월 수 검증 (b): 부모 A=6개월, B=6개월 (각 2,000만)
11. 공통 개월 수 검증 (c): 부모 A=12개월, B=1개월 (A: 2,310만, B: 250만)
